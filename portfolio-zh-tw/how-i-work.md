# 我怎麼工作

五個步驟，以及每一步結束時你手上會有什麼。步驟叫什麼名字不重要，重要的是你隨時知道我們走到哪一步。

## 1. 通話與報價（第 0 週）

三十分鐘的通話，談你需要什麼、拿來做什麼。三個工作天內給你固定報價，寫清楚包含什麼、不包含什麼，以及費用內含幾次修改。

**你拿到：** 一份可以回答「好」或「不好」的報價。

## 2. 先看再畫（第 1 週）

我會讀你手上已有的資料；如果有實體場所，就到現場看看，並和兩三位會用到成果的人聊聊。印刷案我還會先找印刷廠談，因為機器的限制決定了一半的設計。

**你拿到：** 一頁摘要，寫我看到什麼，以及我建議的方向。

## 3. 初步想法（第 2 週）

兩三個方向，畫得很簡單，一起給你看，附上我的推薦和理由。這時候可以說「就那一個」，也可以說「都不是」。

**你拿到：** 幾個可以選擇的方向，每個都有一段短短的說明，講它放棄了什麼。

## 4. 修整（第 3 到 4 週）

只剩一個方向。費用內含兩次修改。我會把收到的每一則意見編號，再逐號回應，這樣雙方都知道決定了什麼。

**你拿到：** 完整的設計，而且在實際會用到的地方測試過。

## 5. 交付（第 5 週）

可直接送印或交給工程師的檔案、一份使用說明，以及一次帶你走過一遍的通話。交付之後一個月內，有問題都可以問我。

**你拿到：** 所有東西，格式是不需要我在場，別人也打得開的。

## 我需要你做的

指定一位能拍板的人；每一輪只給我一份整合過的意見，不要分好幾份；還有，早一點告訴我印刷廠或工程師的聯絡方式。

## 我不會做的事

保證我無法衡量的成果、為了提早結束而趕一輪修改，或是把取捨藏起來不說。如果預算買不到好的答案，我寧可在第一次通話就告訴你。
