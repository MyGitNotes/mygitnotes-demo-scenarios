# 櫃檯核對取件碼

**執行：** @品蓁。**最後負責：** @沛珊。規格是[取件流程](../project-zh-tw/spec-pickup-flow.md)。

鄰居出示簡訊裡的六位數字，老闆在 App 裡輸入，畫面顯示是哪個包裹，點一下就標成已取。一組取件碼只能用一次，包裹取走之後就失效。

## 完成的標準

- 正確的取件碼剛好對到一個等待中的包裹，畫面寫明是誰的。
- 已經用過或根本不存在的取件碼會被拒絕，訊息短到老闆可以直接念給鄰居聽。
- 用姓名比對仍然是最後的備案，畫面上也寫明這點。要怎麼寫，是下面還沒決定的事。
- 取件不會刪除包裹，包裹離開等待清單，但會留在歷史紀錄裡。

## 備註

櫃檯畫面是老闆最常在「鄰居站在面前等」的時候用的畫面，所以目標是從輸入第一個數字到出現「已取」不超過 10 秒。@郁雯 把數字畫得很大，只留一個主要按鈕；第一版先在 @品蓁 自己的手機上跑。

規格留下的問題：取件碼不對、鄰居改報姓名的時候，老闆會看到什麼。兩位鄰居可能同名，所以畫面要讓「用姓名」看起來就像備案。
