# 參考答案

1. 光、水和二氧化碳。
2. 行光合作用時，吸收二氧化碳，釋出氧氣。
3. 葉綠體，裡面有葉綠素。
4. 植物會變黃白，因為沒有光就製造不出葉綠素，莖也會又高又細地徒長；同時做不出葡萄糖，只能耗用原本儲存的養分而變弱。
5. 植物製造的葡萄糖，是每一條食物鏈的起點；植物釋出的氧氣，則是動物呼吸需要的。
