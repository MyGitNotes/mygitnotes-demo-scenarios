# 植物怎麼製造養分

:::summary{slide="1"}
植物用光、水和空氣，自己製造養分。
:::

---

## 什麼進去，什麼出來

::::grid{cols="2"}
:::cell
### 進去
- 陽光
- 水，從根吸收
- 二氧化碳，從空氣進入
:::
:::cell
### 出來
- 葡萄糖（植物的養分）
- 氧氣（釋放到空氣中）
:::
::::

---

## 過程

::::flow{direction="horizontal" arrow="→"}
:::step{icon="☀"}
**光**被葉子裡的葉綠素吸收
:::
:::step{icon="💧"}
**水**從根往上送
:::
:::step{icon="🌿"}
**反應**在葉綠體裡，把水和二氧化碳結合
:::
:::step{icon="🍬"}
製造出**葡萄糖**，放出**氧氣**
:::
::::

---

## 比較：白天和夜晚

::::grid{cols="3"}
:::cell
**白天**

進行光合作用。釋出氧氣，吸收二氧化碳。
:::
:::cell
**夜晚**

沒有光，就沒有光合作用。植物仍然會消耗一些養分來維持生命。
:::
:::cell
**重點**

植物兩件事都做：有光時製造養分，也隨時在使用養分。
:::
::::
