# Vectors

What is a vector, in one picture and in one formula?

---

**Picture:** an arrow with a length and a direction. Two arrows that point the same way and have the same length are the same vector.

**Formula:** an ordered list $\mathbf{v} = (v_1, \dots, v_n)$ of real numbers.

You can add vectors and scale them, and that is all the structure we need. Next: what can we reach with those two moves? See [Span](card-span.md).
