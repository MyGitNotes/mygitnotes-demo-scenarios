# 通知

鄰居應該在走去店裡之前，就知道包裹到了。

```mermaid
sequenceDiagram
    participant S as 老闆
    participant A as 貨架小幫手
    participant N as 鄰居
    S->>A: 為「王小姐」登記包裹
    A->>A: 產生取件碼
    A->>N: 「您的包裹已到阿福雜貨店，取件碼 482 913」
    N->>S: 在櫃檯出示取件碼
    S->>A: 確認取件碼
    A->>S: 在櫃檯畫面顯示「已完成取件」
```

每個包裹，鄰居最多收到兩則訊息：到貨通知，以及三天後的一則提醒。取件完成只在櫃檯畫面確認，不另外發訊息給鄰居。

## 驗收條件

- [x] 登記後一分鐘內送出訊息。
- [x] 訊息寫明店名，並附上取件碼。
- [ ] 包裹放了三天還沒取，再提醒一次。
- [ ] 鄰居可以關閉提醒，但第一則訊息一定會送。

## 這一版不做

送達回執、每位鄰居自選語言，以及 LINE 官方帳號和 App 推播這兩個之後再加的管道（先用簡訊）。這幾項都在待排。
