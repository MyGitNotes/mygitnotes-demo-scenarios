# 退貨

## 為什麼

有時候鄰居決定不收了，或是包裹放太久，店裡得退回去。現在這只是紙本清單邊緣的一行潦草字。

## 初步想法

在「等待中」和「已取」之外，多一個「已退回」狀態。老闆選一個原因，鄰居會收到通知，包裹離開貨架。

## 問題

- 退貨需不需要取件碼，像[領取包裹](spec-pickup-flow.md)那樣？
- 誰去通知物流業者？大概是老闆自己，在程式之外處理。
- 包裹放多久之後，才可以退？
