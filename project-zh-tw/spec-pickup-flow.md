# 取件流程

包裹怎麼從貨架到鄰居手上。

```mermaid
flowchart TD
    A[鄰居帶著取件碼來到店裡] --> B{取件碼對得上等待中的包裹嗎？}
    B -- 對得上 --> C[老闆拿出包裹]
    C --> D{鄰居確認是自己的包裹？}
    D -- 是 --> E[標記為已取]
    D -- 否 --> F[留在貨架上，加一則備註]
    B -- 對不上 --> G[改問姓名]
    G --> H{姓名剛好只對上一個包裹？}
    H -- 是 --> C
    H -- 否 --> I[請鄰居回頭看一下訊息]
```

## 規則

- 一組取件碼只能用一次。包裹取走之後，取件碼就失效。
- 比對姓名只是備案，不是第一選擇，因為兩位鄰居可能同名。
- 取件不會刪除包裹。包裹離開等待清單，但會留在歷史紀錄裡。

## 待釐清的問題

- 鄰居請別人代領怎麼辦？有取件碼應該就夠了，但老闆要看得到這個包裹是寄給誰的。
- 老闆可不可以在對不上時強制放行？1.1 版傾向不行。
- 用姓名比對時，要不要請鄰居出示證件？不然任何人報出名字就能領走包裹。
