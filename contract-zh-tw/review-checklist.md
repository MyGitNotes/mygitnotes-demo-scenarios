# 運送合約審閱檢核表

不管誰起草，每份草稿都問同一批問題。一邊讀[合約本文](services-agreement.md)，一邊勾選。

- [x] 立約人是誰？公司名稱登記對不對？
- [x] 到底運什麼、運到哪裡、多久一次？
- [x] 什麼時候付款？逾期會怎樣？
- [x] 合約怎麼結束？會自動續約嗎？
- [x] 雙方都能退出，還是只有一方？
- [x] 賠償上限是多少？包含哪些損失？
- [x] 貨物腐壞的風險誰承擔？
- [ ] 保險證明有沒有附進檔案？
- [ ] [條款變更摘要](clause-changes.md)裡還沒結案的項目，合夥律師簽核了嗎？

可以自己加項目，這份清單就是一般的 Markdown。
