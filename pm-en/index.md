# Cubbyshelf v1.1: the release notebook

This notebook is how a six-person team runs one release of a small product: who owns what, which dates matter, and what is at risk this week. The product is Cubbyshelf, the parcel-holding app. Version 1.1 adds the pickup message and the code check at the counter. The team, the shops and the numbers are all invented.

Release day is Thursday 12 November 2026. Start with [Team and who owns what](team.md).
