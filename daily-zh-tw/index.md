# 一週的每日筆記

這個筆記本是一個人的一週：每天一份筆記，待辦事項帶日期，週末再用一份回顧把幾天串起來。宜庭是自由接案的插畫家，正在趕一個客戶的書封，所有細節都是虛構的。

## 可以試試

1. **把一週當成一頁來讀。** 在「合輯」裡打開「第 43 週一次讀完」，它會把所有標了 `week-43` 的筆記收進一本書，從頭捲到尾。
2. **勾掉一項待辦。** 打開[週五](journal/2026-10-23.md)，勾一個方框，筆記會把完成日期記在那一行後面。
3. **一次看所有待辦。** 打開右側欄的待辦工具，所有筆記裡已逾期、今天和接下來的待辦會排在同一個清單，有開始日期的還會變成甘特圖上的長條。
4. **寫回顧。** [每週回顧](weekly-review.md)是把這週收尾的地方，寫完把狀態從「進行中」改成「已完成」。
5. **用數字讀這一週。** [每週回顧](weekly-review.md)開頭有三個關鍵數字，還有一張每天勾掉多少待辦的長條圖。
6. **隨便改。** 這是示範用的副本，你的修改只留在這個瀏覽器 24 小時，不會影響任何人。
