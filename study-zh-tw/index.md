# 線性代數，一次一張卡片

一門線性代數入門課，照學生平常的記法整理：[課堂筆記](lecture-notes.md)把算式寫完整，每個觀念再各寫一張簡短的**卡片**。每張卡片都連到它所依據的觀念，所以這些筆記同時也是一張地圖。

## 可以試試

1. **翻卡片。** 在「合輯」打開「線性代數卡片」，按「開始學習」。每張卡先出現題目，按「顯示下一頁」才看到答案。評分之後，卡片會進入複習排程的下一個階段。
2. **看算式。** [課堂筆記](lecture-notes.md)用 KaTeX 排版，有行內公式，例如 $\mathbf{v}\in\mathbb{R}^n$，也有獨立成行的方程式。
3. **打開關聯圖。** 打開「概念地圖」合輯，或進入圖譜頁：每張概念卡是一個節點，觀念之間的連結就是邊。從[向量](card-vector.md)出發，沿著箭頭走到[特徵值](card-eigenvalue.md)。
4. **新增一張卡。** 隨便從一張卡開始：第一頁是題目，每個 `---` 之後的頁面都是答案頁。
5. **在曲線上找特徵值。** [課堂筆記](lecture-notes.md)的最後，把例題的多項式畫成一張 `line` 折線圖，曲線穿過 0 的地方就是特徵值。
6. **隨便改。** 這是示範用的副本，你的修改只留在這個瀏覽器 24 小時，不會影響任何人。
