# 懷疑與異議

兩位作者相隔兩個世紀，卻有同一個習慣：一個信念，要熬過它最強的反對意見，才算是你的。

| | 笛卡兒 | 彌爾 |
| --- | --- | --- |
| 反對從哪裡來 | 從內部：他自己想出來的懷疑論 | 從外部：不同意的其他人 |
| 剩下什麼 | 一個確定的東西，[我思](quote-cogito.md) | 一個帶著理解去持有的看法 |
| 保護的是什麼 | 認知者自己的理由 | 異議者的自由，見[封殺意見](argument-silencing.md) |

## 我思，畫成論證圖

笛卡兒這一邊，照上面彌爾那篇的做法，也畫成論證圖。

::::argument-map{title="我思" source="笛卡兒《沉思錄》（1641）第二沉思；利希滕貝格（Lichtenberg）《雜記本》（Sudelbücher）K 本"}
- [C] **只要我在思考，我就存在**｜第二沉思

:::reason{to="C" id="R1" label="騙子也無法讓我什麼都不是"}
- [D] 如果有誰在欺騙我，我就必須存在，才有被騙的對象｜第二沉思
- [T] 懷疑和被欺騙，本身就是思考的方式；笛卡兒把懷疑、理解、肯定、否定、意願、想像和感覺都算作思考｜第二沉思
:::

:::objection{to="C" id="O1" label="利希滕貝格"}
- 被給予的只有「有思考」，不是「有一個我在思考」：該說「思考發生了」，就像說「閃電了」｜利希滕貝格《雜記本》K 76
:::

:::objection{to="O1" id="O2" label="確定性有範圍"}
- 我思只主張：思考持續時，存在就有保證；笛卡兒隨即補了一句，他還不了解這個「我」是什麼｜第二沉思
:::
::::

## 一個還沒想完的問題

笛卡兒獨自懷疑，彌爾需要別人。一個人單獨懷疑，能不能做到和一個社群的異議一樣好？我傾向認為不行，因為我懷疑的內容，都來自我已經聽過的話。這會讓彌爾的論點比他自己說的更強。
