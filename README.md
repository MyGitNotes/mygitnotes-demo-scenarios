# MyGitNotes demo scenarios

Sixteen small notebooks, one per scenario and language, for showing what MyGitNotes does. Every person and company in them is fictional, and the texts quoted are in the public domain.

| Scenario | What it shows |
| --- | --- |
| `trpg` | A Focus that lays out outline, NPC sheets, handouts and a map; clues on a Kanban |
| `contract` | Version history of a contract, v1 to v3, with reviewer comments |
| `daily` | Daily notes with dated tasks, a weekly review and a reading list |
| `study` | Course notes with maths, flashcards and a concept graph |
| `reading` | Parallel original and translation, a bibliography, linked argument notes |
| `writing` | A book outline and chapters that read as a book |
| `project` | A product spec on a Kanban, with diagrams |
| `teaching` | A lesson laid out as slides |

Each scenario has an English notebook (`<scenario>-en`) and a Traditional Chinese one (`<scenario>-zh-tw`). Open the `index.md` in a notebook first: it says what to try.

The repository root is a MyGitNotes workspace (`.mygitnotes.yaml`), so point a MyGitNotes checkout at it to browse everything.
