# 設計需求書：苔門茶舖

周老闆（業主）在開案會議上確認。以下是我邊聽邊記、當天晚上整理過的內容。

## 客戶

苔門茶舖是一間賣散茶的小店，附一個只有六個座位的品茶吧台，十一月會開在老街紅磚街屋裡一間舊裝訂工坊的店面。周老闆直接向三位小農進貨，另外調了兩款自家配方茶。她手上有店面租約和一個店名，除此之外什麼都沒有：沒有標誌、沒有包裝，也還沒有網站。

## 她要什麼

一套能用在四樣東西上的識別，這四樣她都已經編好預算：

1. **茶罐**：裝散茶，三種容量，共用一張標籤版型。
2. **側招**：掛在門口上方，另加一組玻璃貼。
3. **訂購 App**：給常客用的簡單版本，由合作的外部工程師開發。
4. **海報**：每月一次品茶夜用。

## 目標

- 傍晚路過的鄰居，不用看字，只憑招牌就認得出這間店。
- 茶罐放在家裡要好看，擺在好杯子旁邊也不突兀，不能像「禮盒」。
- 不要有「養生」或「茶道」的味道。周老闆的客人只是想喝一杯像樣的茶，不是要過什麼生活風格。

## 限制

| 項目 | 限制 |
| --- | --- |
| 預算 | 總價固定，第一次提案後含兩次修改 |
| 印刷 | 茶罐標籤在牛皮紙上印兩個專色；招牌請在地的招牌師傅手繪 |
| 時程 | 第 2 週提案、第 3 週交付完稿、第 5 週開幕 |
| 現有資源 | 店名「苔門」（來自店面所在的巷名）、拱形門框，其他都沒有 |

## 不包含

網站設計、攝影、單支茶款的命名，以及茶罐以外的食品包裝。

## 帶回去的問題

- 周老闆要不要把英文店名全部大寫？（她沒有意見，我決定之後再向她說明理由。）
- 招牌師傅畫得出多細的線？（設計線條之前先問清楚。）
